# Projet-Lab-Fin

Un projet web présentant les fonctionnalités et services avec sections de contact.

## 📁 Structure du projet

```
├── index.html              # Page d'accueil
├── contact.html            # Page de contact
├── components.html         # Composants réutilisables
├── feature1.html           # Fonctionnalité 1
├── feature2.html           # Fonctionnalité 2
├── feature3.html           # Fonctionnalité 3
├── feature4.html           # Fonctionnalité 4
├── script.js               # Scripts JavaScript
├── style.css               # Styles CSS
├── contact-style.css       # Styles du formulaire de contact
├── contact-script.js       # Scripts du formulaire de contact
└── assets/                 # Dossier des images et ressources
    ├── hero.jpg
    ├── feature1.webp
    ├── feature2.jpg
    ├── feature3.png
    ├── feature4.png
    └── ...
```

## 🚀 Utilisation

1. Ouvrez `index.html` dans votre navigateur pour accéder à la page d'accueil
2. Utilisez la navigation pour explorer les différentes fonctionnalités
3. Consultez la page de contact pour envoyer des messages

## 📝 Fichiers clés

- **index.html** - Page principale du site
- **contact.html** - Formulaire de contact
- **style.css** - Feuille de styles principale
- **script.js** - Logique JavaScript globale

## 💡 Fonctionnalités

- ✅ Pages responsives
- ✅ Section contact interactive
- ✅ Présentation de 4 fonctionnalités
- ✅ Galerie d'images
